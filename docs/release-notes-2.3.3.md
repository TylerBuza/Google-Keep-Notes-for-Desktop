## Google Keep Notes for Desktop 2.3.3

**Unofficial, experimental, and unsigned. [Read the security and verification notice before installing.](https://github.com/TylerBuza/Google-Keep-Notes-for-Desktop/blob/main/docs/RELEASES.md#security-notice-for-233)**

### A few things that make Keep feel more at home

- Proper in-app Settings: Windows startup, taskbar options, text size, sync and account controls.
- Your existing cloud labels in the sidebar, plus a read-only Archive view.
- Two-way sync on by default after a verified read, with conflict and uncertain-write safeguards intact.
- Matching Keep icons throughout, plus the updated Tyler Buza credit and buza.dev link.

Download **Google-Keep-Notes-for-Desktop-Setup-2.3.3.exe** below. Save your edits and
use **tray → Quit** before upgrading. Two-way sync includes queued local edits;
you can pause it in Settings. Checksums and verification reports are attached.
Fresh multi-engine binary analysis is currently unavailable.

Still built on LukeCGG's original sticky-note/pinning foundation, significantly
expanded into the native Keep-style experience. Original credit and AGPL-3.0 retained.
